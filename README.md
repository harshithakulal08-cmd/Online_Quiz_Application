Online Quiz Application

About the Project

The Online Quiz Application is a simple and interactive web-based quiz developed using HTML, CSS, and JavaScript.

It allows users to answer multiple-choice questions and test their knowledge.

Technologies Used

- HTML – Structure of the application
- CSS – Styling and user interface
- JavaScript – Quiz functionality and interactivity

Features

- Multiple-choice questions
- Interactive quiz interface
- Next Question button
- Simple and user-friendly design

Project Files

- "index.html" – Main webpage
- "style.css" – Application design
- "script.js" – Quiz functionality

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.
